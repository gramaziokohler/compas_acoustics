## What was built

Goal: estimate scattering coefficients (s), the diffusion coefficient (d), polar balloons and an `AcousticMaterial` for 3D objects (1-10 m, cavities allowed) mounted on a surface, driven from Grasshopper.

Decisions the user made up front: the default is a fast geometric preview; Kirchhoff/SBR and BEM are options passed explicitly; a chain of components is fine; simple relief patterns keep using `scattering_coefficients_from_depth`; cavities can be deep.

### Python (`src/compas_acoustics/lab/`, `worker/api.py`, `pb/`)
- `measure_scattering(method="geometric"|"kirchhoff"|"bem")`, default geometric.
- Geometric method (`geometric.py`): heuristic s = s_max * (1 - exp(-(k h)^2)), with h = max(2 sigma, |mean|) of the surface depth. It is a preview, not a measurement.
- Setup: the object sits on a rigid baffle at z=0 outside its footprint; the lost fraction is an extra bin; rays that exit at the horizon are binned.
- `raycast.py`: `RayCaster` (trimesh + embreex), `first_hits(origins, directions, exclude=None)`.
- Proxy reference: `as_drawn(mesh, reference=)` compares against a proxy of the same bounding box and bottom area (tolerance 1e-2).
- Worker functions: `make_scattering_sample(..., frame=None)`, `run_scattering_lab` (returns `result`, `scattering_coefficients`, `octave_bands`, `warnings`, `notes`), `polar_balloon`, `lab_material`.
- Wire messages in `acoustics.proto`: `ScatteringSampleData`, `ScatteringResultData`, `ArrayData`. Conversions are in `pb/conversions.py` and fixtures are generated by `tests/pb_fixtures/generate.py`.
- Heuristic caveats come back as `notes` (`HEURISTIC_NOTES` in `lab/scattering.py`, `MATERIAL_HEURISTIC_NOTE` in `worker/api.py`), split from real `warnings` by `_split_notes`. `result.warnings` and the Python API still carry them.

### C# (`csharp/CompasAcoustics.Grasshopper/`)
- Components: Scattering Sample, Scattering Lab, Polar Preview, Lab Material (`Components/LabComponents.cs`, `LabRequests.cs`, `LabResults.cs`, specs under `Components/Specs/`, goo in `Data/LabGoo.cs`).
- The geometric method runs in the background on change; kirchhoff/bem run only on the Run button. `LabRequests.RunKey` clears the sample guid so a re-solved Sample does not retrigger a run.
- A stale wave result shows a warning and a status (`LabResults.StaleNotice`).
- The `plane` input maps to the worker `frame` kwarg, so objects need not sit on World XY.
- Notes show as component Remarks (`ShowNotes`).

### Pitfalls found while driving Grasshopper through lamcp
- Wiring by parameter index fails because components have hidden control ports. Body dropdowns are stored in `ControlPort(name).PersistentData`; `SetChoice` did not apply.
- `EmitObject` needs the component type GUID.
- Do not use the global name `objs` in `run_python_script`; the bridge uses it. Marshal to the UI thread with `Rhino.RhinoApp.InvokeOnUiThread`.
- The bridge toggle must be switched on again after every Rhino restart. The plugin must be rebuilt and reinstalled (`invoke build-gha`) before a re-check; check the build time.
- Place test objects below y=520 on the canvas and restore the canvas afterwards.
- Disc mode needed a periodic tile to give sensible results.
- C# tests run outside Rhino, so they cannot construct Rhino Mesh/Brep/Plane. Real-worker tests need `COMPAS_ACOUSTICS_WORKER_PYTHON=/opt/miniconda3/envs/compas_acoustics/bin/python`.
- Two implementers must not edit `tests/test_worker_api.py` or `worker/api.py` at once; queue the second.
