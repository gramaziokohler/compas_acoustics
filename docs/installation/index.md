# Installation

`compas_acoustics` is not on PyPI yet. There are two ways to install it:

* **[In Rhino 8 and Grasshopper](grasshopper.md)**, with the installer of a GitHub release. It installs the plugin's
  components and the worker, the Python environment they compute in. Choose this to work on the canvas.
* **[In Python](python.md)**, from the git repository, to script with the package in your own environment.

The two are independent: the Grasshopper installer does not need a Python installation of your own.
