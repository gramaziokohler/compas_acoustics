    API reference¶

    Every public class and function is importable from compas_acoustics.

    Scene and model¶

    Scene ¶

    Scene(name: str, description: str = '', sampling_rate: int = None)

    Bases: _PackageDtype, Data

    The acoustic model of a room: its surfaces with materials, sources, receivers, and the impulse responses simulated for them.

    Parameters:

    Name Type Description Default
    name str
    		required
    description str
    		''
    sampling_rate int

    The sample rate every simulation method runs at; default 48000.

    		 None

    Examples:

    >>> import compas_acoustics as ca
>>> scene = ca.Scene("office")
>>> scene.add_acoustic_objects(ca.AcousticObjectsLibrary.shoebox_room(6, 5, 3, materials=ca.AcousticMaterial("wall", 0.2, 0.1)))
>>> scene.add_source(ca.Source("talker", 1.5, 1.5, 1.6))
>>> scene.add_receiver(ca.Receiver("listener", 4.0, 3.0, 1.2))
>>> len(scene.acoustic_objects), len(scene.sources), len(scene.receivers)
(6, 1, 1)
>>> scene.sampling_rate
48000

    from_obj classmethod ¶

    from_obj(filepath, materials=None, name=None)

    One acoustic object per g group of a Wavefront OBJ file.

    Faces before any g line are in 'default'; a file without g lines is grouped by its o lines. A group that recurs is merged into the first. Objects are named '<name>_<group>'. Coordinates are metres, not rounded (RoomGeometry welds them). Faces may use i, i/j, i//k or i/j/k indices, negative ones relative; faces with fewer than three distinct vertices are dropped. Every object is a boundary; mark furniture with assign_roles_by_group.

    Parameters:

    Name Type Description Default
    filepath str
    		required
    materials [`AcousticMaterial`][compas_acoustics.materials.AcousticMaterial] or dict

    One material for every group, or one per group name as assign_materials_by_group takes them. A scene with an object without a material cannot be simulated.

    		 None
    name str

    The prefix of the objects' names; defaults to the file name.

    		 None

    Returns:

    Type Description
    list of [`AcousticObject`][compas_acoustics.acoustic_object.AcousticObject]

    RoomGeometry dataclass ¶

    RoomGeometry(vertices: ndarray, faces: Tuple[Tuple[int, ...], ...], face_materials: Tuple[str, ...], face_names: Tuple[str, ...], face_roles: Tuple[str, ...], materials: Dict[str, SurfaceMaterial], is_closed: bool, open_edge: Optional[Tuple[Tuple[float, ...], Tuple[float, ...]]] = None, obstacle_faces: Tuple[Tuple[int, ...], ...] = (), obstacle_face_materials: Tuple[str, ...] = (), mergeable_faces: int = 0)

    Every surface of a scene as one room: welded, oriented, materials on SYNTHESIS_BANDS.

    Faces are listed boundary first, then the front and then the back copy of every obstacle face. is_closed says whether the boundary faces close a volume; open_edge holds the end points of the first edge that prevents it.

    from_scene classmethod ¶

    from_scene(scene, merge_coplanar: bool = True, weld_tolerance: float = 0.001) -> RoomGeometry

    Collect, weld, orient and validate every surface of scene.

    Boundary faces that close a volume are wound outward; otherwise they are kept as drawn, with a UserWarning. Obstacle faces are stored twice, OBSTACLE_OFFSET either side and wound opposite, since a wall reflects off one side only. merge_coplanar joins coplanar faces of one object and material into larger walls (a triangulated CAD mesh); False keeps them and warns where it could. weld_tolerance, in metres, is a CAD model's usual absolute tolerance.

    is_inside ¶

    is_inside(point) -> bool

    Whether point is in the air: inside a closed boundary (anywhere in an open scene), outside every closed obstacle.

    Decided by generalised winding numbers over the drawn faces, so the obstacle copies play no part.

    to_pra ¶

    to_pra(fs: int, max_order: int, ray_tracing: bool = False, air_absorption: bool = False, enclosure_only: bool = False, air: Optional[AirConditions] = None) -> Room

    The pyroomacoustics room, one wall per face, materials resampled to its octave grid (nine bands at 48 kHz).

    Bands above 8 kHz hold the 8 kHz value, where linear extrapolation could pass 1. A material without scattering scatters DEFAULT_SCATTERING. enclosure_only leaves the obstacles out. The room answers is_inside with is_inside. air (default AirConditions()) sets the speed of sound (Cramer) and, with air_absorption, the ISO 9613-1 absorption, in place of pyroomacoustics' own 343 m/s and absorption table.

    without_obstacles ¶

    The enclosure alone.

    Source ¶

    Source(name: str, x: float, y: float, z: float, directivity: str = None, direction: Vector = None, sound_file: str = None)

    Bases: _PackageDtype, Point

    A sound source: position, directivity and facing, an optional sound file, and its level.

    spl is the free-field level on its axis at 1 m per octave band, 125 Hz to 8 kHz, in dB re 20 uPa (the voice presets give the talker levels of ANSI S3.5-1997). On the package scale the direct sound is 1 / (4 pi r) with gain 1 on axis, so Lp = spl + G - 20 dB (Analyser.sound_pressure_level).

    Mono(image_source_order: int = 3, ray_tracing: bool = True, air_absorption: bool = True, n_rays: Optional[int] = 20000, energy_thres: float = 1e-07, duration: Optional[float] = None, receiver_radius: float = 0.5, seed: Union[bool, int] = True, normalize: bool = True, air: Optional[AirConditions] = None)

    Audio¶

    Auraliser ¶

    Auraliser(name: str, impulse_responses, anechoic_sounds=None, description: str = None, sampling_rate: int = None, level: str = 'relative', headroom_db: float = -1.0)

    Convolves impulse responses with their anechoic sounds and sums them.

    The signal keeps the format of its responses (format): 'mono', 'binaural' (two ears), or 'ambisonic' (ACN/SN3D, (order + 1)**2 channels at the highest order present; N3D is converted). Responses of different formats cannot be mixed: there is no decoding. Responses are used at their raw level, so their level differences are kept; level sets the output level on export:

    • 'relative': one gain for a group of renders, the loudest peaking at headroom_db.
    • 'individual': each render peaks at headroom_db.
    • 'none': no gain; warns above 0 dBFS.

    Parameters:

    Name Type Description Default
    name str

    Lowercase, without spaces.

    		 required
    impulse_responses dict or list

    A list of ImpulseResponse (ACN/SN3D when they state no convention), or a dict of ids to dicts with 'ir' ((samples,) or (samples, channels)), 'sampling_rate', 'ambisonic_order', 'channel_order' ('acn') and 'normalization' ('sn3d' or 'n3d'). All of one format.

    		 required
    anechoic_sounds dict or list

    File paths, or a dict of ids to dicts with 'filepath'; paired with the responses by id when both are dicts with the same ids, else by position. Default: each response's source's sound_file.

    		 None
    description str
    		None
    sampling_rate int

    Responses and sounds are resampled to it. Default: that of the first response.

    		 None
    level str

    'relative' (default), 'individual' or 'none'.

    		 'relative'
    headroom_db float

    Target peak in dBFS for 'relative' and 'individual'; default -1.

    		 -1.0

    Examples:

    >>> import compas_acoustics as ca
>>> sound = ca.Defaults().ANECHOIC_SOUNDFILES_LIBRARY_PATH + "/female_speech.wav"
>>> scene = ca.Scene("office")
>>> scene.add_acoustic_objects(ca.AcousticObjectsLibrary.shoebox_room(6, 5, 3, materials=ca.AcousticMaterial("wall", 0.2, 0.1)))
>>> scene.add_source(ca.Source("talker", 1.5, 1.5, 1.6, sound_file=sound))
>>> scene.add_receiver(ca.Receiver("listener", 4.0, 3.0, 1.2))
>>> responses = scene.simulate(ca.Mono(ray_tracing=True, n_rays=2000, duration=0.5))
>>> auraliser = ca.Auraliser("office", list(responses.values()))
>>> auraliser.format, auraliser.convolve().shape[1]
('mono', 1)
